# Сборка кубика Рубика — пошагово · Rubik's Cube Solver & Trainer

Интерактивный решатель и тренажёр сборки кубика Рубика. Задаёшь свой кубик
(цвета как на реальном) — программа ведёт к сборке по шагам и учит собирать самому.
Статический сайт, без сборки и сервера.

**Живая версия:** https://ksander314.github.io/rubik-cube-solver/

## Возможности

- **Ввод кубика** — рисуешь цвета на плоской развёртке или **прямо на 3D-кубике**
  (клик — покрасить, перетаскивание — повернуть). Палитра **настраивается** (любой
  оттенок и название каждого из 6 цветов). Ввод также через строку ходов или ссылку.
- **Проверка ввода** — понятные ошибки (неверные количества, невозможная позиция) с
  подсветкой, и **поиск физического дефекта** (повёрнутый угол / перевёрнутое ребро):
  программа собирает всё остальное и показывает, что чинить руками.
- **Пошаговая сборка** — послойный метод; на каждом шаге видно цель этапа, **название
  алгоритма** и что он делает, крупный ход с направлением. 3D-кубик **анимирует поворот
  слоя** синхронно с шагами (вперёд и назад).
- **Учебный режим** — нотация и термины, справочник из 6 ключевых алгоритмов (с показом
  на кубике), **тренажёр по этапам** (отрабатывай один этап на случайных позициях),
  **«Узнай случай»** (распознавание шага последнего слоя), режим **«без подсказки»** и
  **трекер прогресса** (этап засчитывается, когда собран без подсказки).
- **Мелочи** — буквы на наклейках для дальтоников, ссылка-шаринг позиции, сохранение
  кубика и схемы цветов в браузере, адаптив под телефон (залипающие кнопки показа внизу).

## Запуск

Открыть `index.html` в браузере — без сборки и сервера:

```sh
open index.html        # macOS
```

## Структура кода

```
cube.js     Модель кубика (кубики), движок ходов, конвертация наклейки↔состояние, валидация.
solver.js   Послойный решатель. Поиск по ходам (крест) и по целым алгоритмам («триггерам»),
            каждый шаг сверяется с движком — на выходе только корректные последовательности.
ui.js       Развёртка/3D, рисование, валидация, пошаговый показ, учебные режимы.
index.html  Разметка.   style.css  Стили (+ адаптив).   favicon.svg
.github/workflows/test.yml   CI: node cube.js + node solver.js на каждый push.
```

## Тесты

```sh
node cube.js     # 34 проверки: таблицы ходов, round-trip наклеек, правила решаемости
node solver.js   # решает 2000 случайных кубиков, проверяет, что каждый собран (код 1 при сбое)
```

## Метод

Послойная сборка (для новичков): крест снизу → углы снизу → средний слой → крест сверху →
разворот углов → расстановка углов → расстановка рёбер. ~110 ходов — длиннее оптимального,
но каждый этап понятен и повторяем.
